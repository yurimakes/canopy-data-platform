04REVIEW

설정 결과 확인

기업별로 어떤 선택지가 저장됐는지 확인합니다. 현재는 같은 브라우저의 데모 저장값입니다.

현재 데모에서 할 수 있는 것
  • Power BI 화면 기준 KPI 스냅샷과 주차별 상세 현황 확인
  • mission-policy-v3.2 기준 미션 카탈로그 조회
  • 기업별 미션 템플릿 선택 및 브라우저 저장
  • 저장된 기업 선택 결과 조회와 CSV 다운로드
운영 연동 전 확인이 필요한 것
  • 현재 KPI는 실시간 Power BI Embedded 데이터가 아니라 정적 스냅샷입니다.
  • 기업 선택값은 실제 Cosmos DB나 Weekly Pipeline에 저장되지 않습니다.
  • 현재 정책은 system_assigns_missions = true이므로 기업 선택이 실제 미션 배정에 반영된다고 표현하면 안 됩니다.
  • 실서비스 연결 시 저장 schema, 권한, func-canopy-dev API, E2E 검증이 추가로 필요합니다.
