# CANOPY 공개 사본 안내

CANOPY는 이동 수단 분석, 탄소 계산, 미션·보상 UI와 관리자 캠페인 화면을 구현한 팀 프로젝트입니다. 이 저장소는 팀의 허락을 받아 공개용으로 정리한 별도 사본입니다. 원본 저장소와 서비스 계정은 비공개로 유지합니다.

## 실행 및 화면

README의 기존 개발·실행 안내를 따르세요. README에 첨부한 모바일 4장은 기존 예시 데이터로 실행한 Expo web 화면이며 관리자 2장은 정적 데모 화면입니다. 예시 보상은 실제 교환 상품이나 제휴를 의미하지 않습니다. 이동 결과의 합성 GPS·기준선 예시는 실제 사용자의 탄소 절감 실적을 입증하지 않습니다.

실제 iPhone, 위치 권한, 실시간 GPS, 운영 클라우드 및 전체 Spark 파이프라인의 실행 검증은 이 공개 준비 범위에 포함하지 않았습니다. 서비스 연결에는 본인이 관리하는 계정과 환경 설정이 필요합니다. 예시 UI를 보기 위해 원본 서비스의 자격 증명을 복원하지 마세요.

## 공개 데이터와 누락된 입력

공개 사본의 포함 데이터와 출처·라이선스·버전 한계는 [DATA_SOURCES.md](../DATA_SOURCES.md)를 확인하세요. 공개 데이터가 있다는 이유만으로 모든 과거 파이프라인을 그대로 재현할 수 있는 것은 아닙니다.

AIHub 원천·재생 자료, GeoLife, KTDB 학습 입력과 관련 모델, TMAP 응답 fixture 중 공개 사본에서 제외한 파일은 과거 코드·매니페스트에서 경로로 언급될 수 있습니다. 그러한 참조는 파일의 포함이나 재배포 허가를 뜻하지 않습니다. 과거 매니페스트의 경로·해시는 해당 시점 기록이며 현재 공개 사본의 완전한 배포 목록이 아닙니다.

특히 KTDB 기반 과거 인구 기준선 추론은 학습 입력, 행정동 중심점·매핑과 모델을 요구합니다. `build_expected_features`는 해당 CSV를 직접 읽으므로 입력을 별도로 확보하지 않으면 실행할 수 없습니다. shared runtime의 `CANOPY_KTDB_REFERENCE_ROOT`와 `CANOPY_KTDB_MODEL_PATH` 설정 또는 기존 provider 연결에는 적법하게 확보한 호환 자료가 필요합니다. 제외된 자료를 이 공개 저장소에 다시 커밋하지 마세요. README의 예시 UI는 이 전체 추론 경로를 검증한 결과가 아닙니다.

## 검증 범위

2026-10-07~08 공개 사본 준비 과정에서 Python 테스트 135개와 앱 테스트 107개가 통과했고, 타입 검사와 production web build도 통과했습니다. 도달 가능한 공개용 이력과 선정한 현재 파일에 대한 보안 검사 결과를 위치별로 검토해 미해결 항목 0개를 확인했습니다. 이는 검사 범위 밖의 시스템이나 향후 변경까지 보증하는 고지가 아닙니다. 화면 6장은 실제 저장소 UI를 실행해 캡처하고 시각 검토했습니다.

## 이력과 권리

공개 정리 시 기존 커밋 1,859개와 부모 관계·날짜·시간대·메시지를 보존하고 승인된 파일·내용·기여자 연락처를 정리했습니다. 내용이 바뀐 커밋의 해시는 원본과 다르며 원본 커밋 서명은 공개 사본에서 그대로 검증되지 않습니다. 이후 main에 공개 안내·화면 문서 커밋을 추가합니다. 나머지 브랜치는 정리된 과거 개발 이력입니다. 원본의 PR·리뷰·이슈는 이 사본으로 옮기지 않았습니다.
